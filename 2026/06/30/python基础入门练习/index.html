题目1：判断偶数

要求：
输入格式：输入一个整数。
输出格式：输出判断结果。
输入示例 输出示例

示例 2 1 1 不是一个偶数

输出格式：判断其是否构成三角形并输出。

4

题目4：判断密码

描述：编写程序，从键盘输入用户名和密码，要求先判断用户名再判断密码，如果用户名不正确，则直接提示用户名输入有误；如果用户名正确，则进一步判断密码，并给出判断结果的提示。
提示：正确的用户名为“admin”，密码为“123456”。
要求：
输入格式：分别输入用户名和密码。
输出格式：分别判断用户名和密码：
如果均为正确则输出“输入正确，恭喜进入！”；
如果用户名错误则输出“用户名有误，请重试！”；
如果密码错误则输出“密码有误，请重试！”。
输入示例 输出示例
示例 1 admin 输入正确，恭喜进入！
123456
示例 2 ad 用户名有误，请重试！
123456
示例 3 admin 密码有误，请重试！
654321

题目5：小型计算器

描述：编写程序，开发一个小型计算器，从键盘输入两个数字和一个运算符，根据运算符（+、-、*、/）进行相应的数学运算，如果不是这 4 种运算符，则给出错误提示。要求：
输入格式：分别输入两个数字与计算符号。
输出格式：如果符号是要求的运算符之一，则输出“符号输入有误！”；如果计算符号正确则输出计算结果“两数之和为：”、“两数之差为：”、“两数之积为：”、“两数之商为：”，结果保留 1 位小数；
如果除数为 0，则输出“除数为 0 错误!”。
输入示例 输出示例
示例 1 1.5 两数之和为： 4.0
2.5
+
示例 2 1 符号输入有误！
2
^

题目12：随机数猜大小

描述：编写程序，生成一个 0-100 之间的随机数，然后让用户尝试猜测这个数字。程序给出猜测方向（更大或更小）的提示，用户继续进行猜测，直到用户猜测成功或者输入一个0-100 以外的数字后退出游戏。
要求：
输入格式：输入一个整数（0-100 之间）。
输出格式：输出判断结果。
样例是随机生成，仅供参考格式，不是唯一答案。
输入示例 输出示例
示例 1 5 您的猜测太小
80 您的猜测太小
99 您的猜测太大
95 恭喜您猜对了
示例 2 50 您的猜测太小
15 您的猜测太大
0 输入数据不在 1-100 之间

def pdhs(num1,num2,num3):
  if num3 == '+':
    eter = num1+num2
    print(f'两数之和为：{eter:.1f}')
  elif num3 == '-':
    eter = num1-num2
    print(f'两数之差为：{eter:.1f}')
  elif num3 == '*':
    eter = num1*num2
    print(f'两数之积为：{eter:.1f}')

    if num2 == 0:

      eter = num1/num2
      print(f'两数之商为：{eter:.1f}')

    print('符号输入有误！')
  return num1,num2,num3

#第11题参考答案
a = int(input('请输入一个整数'))
def pdhs(num):
  b = []
  for i in range(1,num): #这里不能range(1,num+1)；因为因数的定义就是除了本身之外，num除以任何一个数的余数为零，该数就是num的因素；如果这里为num+1,就会导致大部分全是丰沛数
    if num % i == 0:
      b.append(i)
  if sum(b) == num:
    print(f'{num} 是完全数')
  elif sum(b) > num:
    print(f'{num} 是丰沛数')
  else:
    print(f'{num} 是不足数')
  return num
pdhs(a)

#第12题参考答案
def pddx():  # 定义一个名为pddx的函数
  from random import randint  #form先导入random再调用import randint
  a = randint(1,100)
  while True: #  无限循环，直到猜中数字或输入无效
    num = int(input('请输入一个整数')) #  获取用户输入的整数
    if num < 1 or num > 100: #  检查输入是否在1~100范围内
      print('输入数据不在 1~100 之间')
      break #  输入无效，退出循环
    elif num < a: #  比较用户输入与目标数字
      print('您的猜测太小') #  提示输入数字小于目标数字
    elif num > a:
      print('您的猜测太大') #  提示输入数字大于目标数字
    else:
      print('恭喜您猜对了') #  猜中数字，退出循环
      break
pddx()
