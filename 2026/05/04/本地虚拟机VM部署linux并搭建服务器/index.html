本地虚拟机VM部署linux并搭建服务器

2026年05月04日 723 字 大概 3 分钟

简单说一下本地如何部署前后端服务器

windows下载VM虚拟机。提前下好liunx的22.04LtX桌面版ubuntu镜像

新建虚拟机。VM虚拟机硬件兼容就选择17.x即可。先新建空的(不导入镜像)即稍后安装操作系统。选择linux+ubuntu64位；虚拟机命名用全英文，存储位置选择除c盘以外的非中文路径；内存给8g,cpu给4核。硬盘给40g，网络选择地址NAT；其他一路默认下一步即可。以及创建的密码必须记住，你可以创简单点

以下是ubuntu的镜像下载源

清华大学镜像源
阿里云镜像源
中科大镜像源
腾讯云镜像

现在安装Vm toolS工具

  1. 打开终端（Ctrl+Alt+T），先更新软件源：

邮件打开终端

运行
sudo apt update
2. 安装 Open VM Tools（带桌面版组件，支持复制粘贴）：

运行
sudo apt install open-vm-tools open-vm-tools-desktop -y
3. 安装完成后，输入下面内容重启虚拟机或者直接重启客户端：
运行
sudo reboot
由于我们是本地虚拟机，所以不需要公网ip,也不需要解析域名。

会输出类似 192.168.122.100 这样的地址，这就是你的虚拟机 IP，相当于教程里的公网 IP，记下来！

  1. 第二步：安装宝塔面板

执行后按提示输入y确认安装，安装完成后，终端会输出宝塔的关键信息复制保存好：

  1. 第三步：开放 Ubuntu 防火墙端口（不然 Windows 访问被拒绝）
    在 Ubuntu 终端里，开放宝塔和常用服务的端口：
  1. 第四步：Windows 物理机直接访问宝塔面板
    打开你 Windows 主机的浏览器，直接输入终端里输出的宝塔面板地址，比如：http://192.168.122.100:8888/你的安全入口

安装MySQL5.7+PHP7.4+Nginx(默认即可)

组件 版本
PHP 7.4
MySQL 5.7+
Web服务器 Nginx

安装完成后点击左边的站点；填写虚拟机内网域名，根目录是你网站源码的读取目录；一定要记好你的数据库账号密码

最后对你的数据库文件(一般是xxxx.SQL)右键导入数据库；就顺利运行一个前后端都有的网站了
