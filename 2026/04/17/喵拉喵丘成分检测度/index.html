喵拉喵丘成分检测度

2026年04月17日 869 字 大概 3 分钟

刷视频偶然发现了喵拉喵丘成分检测的开源网站喵

作为一名合格的大卡奴喵，必须部署一个属于自己卡奴成分检测度网站喵

点击跳转测试链接

https://exwxsz.github.io/calabiyauify-names/

你喵言喵语的，好可爱喵，我稀饭你喵，跟我介婚喵

问题 1：npm run deploy 报错 Missing script: “deploy”

问题现象

执行部署命令时，终端报错，提示找不到 deploy 脚本，无法部署到 GitHub Pages

根本原因

项目的 package.json 文件中，没有定义 deploy 脚本，npm 不知道 npm run deploy 要执行什么命令

解决办法

打开项目根目录的 package.json

在 scripts 配置块中，添加一行 deploy 命令

"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview",
  "deploy": "gh-pages -d dist" // 新增这一行
}

保存文件后，重新执行 npm run deploy 即可正常部署

问题 2：部署成功但线上页面空白（第一次部署）

问题现象

GitHub Pages 显示部署成功，但访问线上地址时页面完全空白，没有任何内容。

根本原因

你的项目部署在 https://exwxsz.github.io/calabiyauify-names/ 这个子路径下，但 Vite 默认的资源路径是根路径 /，导致浏览器找不到 JS/CSS 等资源文件，无法加载页面。

解决办法

打开项目根目录的 vite.config.mjs
在配置中添加 base 路径，和你的仓库名保持一致：

export default defineConfig({
  base: '/calabiyauify-names/', // 关键修复：设置子路径
  plugins: [vue()],
  // ...其他配置
})

重新执行 npm run build 打包，再 npm run deploy 部署即可

问题 3：修改 base 后，本地预览 / 开发模式也空白

问题现象

修改 Vite 的 base 配置后，不仅线上空白，本地运行 npm run dev 或 npm run preview 也同样是空白页面。

根本原因

项目使用了 Vue Router 的 createWebHistory 路由模式，但路由的 base 配置没有和 Vite 的 base 同步，导致路由无法匹配到页面。

解决办法

打开 src/router/index.js 文件
给 createWebHistory 传入和 Vite 一致的 base 路径：

import { createRouter, createWebHistory } from 'vue-router'
import calabiyauCalculator from '../views/calabiyau-calculator.vue'

const routes = [{ path: '/', component: calabiyauCalculator }]

export default createRouter({
  // 关键修复：和 vite 的 base 保持一致
  history: createWebHistory('/calabiyauify-names/'),
  routes
})

问题 4：页面能显示，但部分图片 / 音效 404 不加载

问题现象

页面主体内容正常，但部分图片（如 title.png、mi3.png）和音效文件无法加载，控制台报 404 错误。

根本原因

代码中引用 public/ 文件夹下的资源时，使用了绝对路径（/图片名.png），但部署在子路径下时，浏览器会去根目录找文件，导致找不到资源。

解决办法

将所有 public/ 文件夹下资源的路径，从绝对路径 /xxx.png 改为相对路径 ./xxx.png，适配本地 + 线上的子路径：

// 修改前（错误）
pic.value = "/mi3.png";
const effects = [{ img: '/death.png', audio: '/death.mp3' }]

// 修改后（正确）
pic.value = "./mi3.png";
const effects = [{ img: './death.png', audio: './death.mp3' }]

模板中的图片也同步修改

<!-- 修改前 -->
<img src = "/favicon.ico">
<!-- 修改后 -->
<img src = "./favicon.ico">

通过 Git 提交并推送代码，4 条命令即可完成

# 1. 查看修改的文件
git status
# 2. 添加所有修改到提交列表
git add .
# 3. 提交代码（备注修改内容）
git commit -m "修复部署问题，项目最终完整版"
# 4. 推送到自己的远程仓库
git push
