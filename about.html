部署教程

1.先复刻原项目的仓库到自己的github仓库git clone https://github.com/你的用户名/calabiyauify-names.git（记得在一个自己能记住的文件夹里面复刻克隆到本地）
2.进入项目文件夹cd calabiyauify-names
3.安装依赖npm install
4.本地测试 npm run dev
5.部署到github page npm run build npm run deploy

再次修改live2d的方案

修改live2d需要去你克隆的根目录下的node_modules\hexo-theme-kira\这个kira主题文件夹更改，一般添加live2d之类的就只在/layout.ejs这个文件修改。例如我是在D盘新建了一个文件夹my-blog；因此我会子啊vscode中打开D:\my-blog\这个文件夹，然后克隆hexo，再克隆kira主题，所有在这个D:\my-blog\这个文件夹就会出现node_modules\hexo-theme-kira\这个kira主题文件夹(我测试过了，无法将它剪切到hexo-theme文件夹，因此就没折腾了，能改就彳亍)然后进入node_modules\hexo-theme-kira\layout\layout.ejs这个文件，在文件中添加live2d即可
